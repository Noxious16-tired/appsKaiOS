# Memakai GymLog dan CaturLite lewat browser (tanpa USB)

## A. Unggah ke GitHub Pages (gratis), bisa dari HP Android/iPhone atau PC
1. Buat akun di github.com. Buat repository baru, nama bebas (misal `apps`), pilih Public.
2. Tekan "uploading an existing file" lalu unggah SEMUA isi folder ini (index.html, folder gymlog, folder catur, dan file .nojekyll). Jaga struktur folder. Dari PC, seret folder-nya; dari HP, unggah zip tidak bisa, jadi lebih mudah dari PC.
3. Settings -> Pages -> Source: "Deploy from a branch", branch `main`, folder `/ (root)` -> Save.
4. Tunggu 1-2 menit. Alamatnya: https://NAMAANDA.github.io/apps/
## B. Buka di Nokia 2720
Browser -> ketik alamat tadi -> pilih GymLog atau CaturLite -> tambahkan bookmark agar mudah dibuka lagi.
## Batasan
- Butuh internet tiap dibuka. Data (latihan, pengaturan) tersimpan di browser HP; jangan hapus data browser.
- Browser KaiOS bisa memakai softkey untuk menu browser sendiri. Jika softkey tidak berfungsi di aplikasi, ini penyebabnya. GymLog dan CaturLite tetap bisa dioperasikan dengan panah, OK, dan Back sebagian besar; sisanya belum teruji.
- CaturLite: impor token dari kartu SD tidak tersedia; ketik token. Sambungan ke Lichess belum teruji dari browser KaiOS.
- Belum diuji di Nokia 2720 sungguhan.
